My ML study notes and coding practice: Markdown notes for concepts, code for trying them out.

| Folder | What's in it |
| --- | --- |
| [`ml-fundamentals/`](ml-fundamentals/) | Core ML concepts (algorithms, evaluation, math), built from the *Ace the Data Science Interview* Machine Learning chapter |
| ↳ [`Machine-Learning-Key-Concepts.md`](ml-fundamentals/Machine-Learning-Key-Concepts.md) | Key concepts, self-check questions, progress checklist |

| `01-…` to `11-…` | One folder per chapter of *Designing Machine Learning Systems* (created as I reach each chapter; see the [main README](../README.md#study)) |

## Rules

- Write ideas in my own words. Don't copy the book.
- A small runnable experiment beats a long summary.
- New topic → a new `.md` file (notes) plus a `practice/` folder (code) next to it.
