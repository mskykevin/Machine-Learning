# Practice

Coding exercises for the [ML key concepts](../Machine-Learning-Key-Concepts.md).
One file per idea, so each one is small and runs on its own.

Suggested naming: `01-gradient-descent.py`, `02-bias-variance.ipynb`, `03-logistic-regression-from-scratch.py`, ...

Ideas to start with:
- [ ] Gradient descent from scratch for linear regression (NumPy only)
- [ ] Plot a learning curve for an underfit and an overfit model
- [ ] Compare L1 vs. L2: which coefficients go to zero?
- [ ] Compute precision, recall, F1, and ROC-AUC by hand, then check them with scikit-learn
- [ ] Decision tree vs. random forest vs. gradient boosting on the same dataset
- [ ] PCA on a small dataset: how many components explain 90% of the variance?
- [ ] k-means: pick k with the elbow method and the silhouette score
